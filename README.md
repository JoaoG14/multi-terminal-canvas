# Canvas Terminals

A VS Code extension that opens a desktop-like canvas with multiple draggable, resizable terminal windows.

## Features

- Multiple independent terminal sessions on a canvas
- Drag windows by title bar
- Resize from any edge or corner
- Minimize to taskbar
- Maximize / restore
- Double-click title to rename
- Special "+ Claude" button to launch Claude Code CLI
- `Ctrl+Shift+T` opens a new terminal

## Usage

Open the Command Palette (`Ctrl+Shift+P`) and run **Canvas Terminals: Open**.

## Requirements

- VS Code 1.94+
- Node.js with `node-pty` native addon (built automatically via `postinstall`)
